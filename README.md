# leonxlnx-industrial-brutalist-ui-skill

> 장식을 지우고, 흑백과 빨강만으로 핵심 정보가 눈에 들어오게 하는 스킬.

## 이 스킬의 역할

AI가 만든 화면이 "예쁘고 무난한" 결과에서 벗어나지 못할 때,
이 스킬은 **장식을 지워 직관적인 화면**을 만들게 합니다.

- 둥근 모서리·그라디언트·그림자를 제거하고, 색은 흰 배경·검정 글씨·빨강 강조 하나만 허용
- 핵심 숫자·제목은 화면에 꽉 찰 정도로 크게, 나머지 설명은 작게 — 크기 차이가 읽는 순서가 됨
- 빨강은 화면에서 단 하나의 강조로만 사용 — 빨강이 붙은 지표가 곧 봐야 할 것

## 누가 쓰면 좋은지

- **대시보드를 만드는 개발자**: 어떤 지표가 중요한지 한눈에 구분되고 싶을 때
- **데이터가 많은 페이지를 만드는 개발자**: 복잡해도 시끄럽지 않은 화면을 원할 때
- **화면을 단순한 걸 좋아하는 프리랜서**: "예쁘고 무난한" 페이지에서 벗어나고 싶을 때
